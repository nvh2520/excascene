# Changelog

## [1.0.0] – 2026-10-28

First public release, accompanying the manuscript prepared for Automation in Construction.

- Code that produced every result reported in the paper: scene generator, sensor and fault models, KinAfford dynamic and BEVFusion-Exca, selectors and evaluator, camera-health monitors, classical and fixed reference policies, analysis and figure scripts.
- Data, checkpoints, per-decision outputs and numerical results: https://doi.org/10.5281/zenodo.23723851 (CC BY 4.0 for original material, with upstream exceptions documented in THIRD_PARTY_NOTICES.md).
